# Bartendro Operator Checklist

## SETUP 
* [ ] Menu planned and appropriate liquids have been procured 
* [ ] Got enough ice, cups, and thirsty friends to run Bartendro
* [ ] Place the bot on a flat surface, ideally a table, that can get wet
* [ ] Twist counter-clockwise the clear plastic part of the dispenser to get it loose from housing
* [ ] This allows access to the peristaltic pumps, ensure the pumps have their rotating gear in place 
* [ ] Ensure that within the pumps the internal tubing is secure as well as the clear external tubes
* [ ] Repeat for all pumps, gears in place and tubing is secure/not loose
* [ ] Ensure the SD card is inserted and power supply is connected
* [ ] Turn on Bartendro, the LED lights will cycle, wait for wifi hotspot to startup
* [ ] Once wifi network is up and webapp is live, connect to it
* [ ] Go to the admin page (tap the logo in top navigation menu) and login (bartendro/partypartyparty)
* [ ] The Dispensers should be automatically identified and are listed after admin login
* [ ] In Dispensers menu use drop downs to select the right liquid for the right pump

## CLEANING CYCLE
* [ ] Get two buckets/large containers, fill one of them with cold water and a very small amount of dish washing liquid
* [ ] Place all intake tubes of the pumps into the bucket with the soapy
* [ ] hold the tubes with your hand so that their ends all stay submerged in the water
* [ ] Place the other bucket on the pouring area, where the outtake tubes will serve the cocktails
* [ ] At the bottom of the in the 'Dispensers' page a green button labeled 'Clean' button
* [ ] After pressing Clean there will be a confirmation pop-up, ensure the buckets are ready now
* [ ] Once pressed the soapy water will pass through all pumps and into the empty bucket, this takes 60 seconds
* [ ] Once completed, empty the excess soapy water back into the first bucket and run the clean cycle again
* [ ] After the 2nd cleaning cycle, empty both buckets and fill one with clear (no soap) water
* [ ] Run the clean cycle again, with the clear water
* [ ] Empty the excess bucket into the first one and run the clean cycle **one more time**
* [ ] After this is done, empty the buckets and use them for ice-cubes

## LOAD BARTENDRO
* [ ] Place bottles or jars with liquids in correct alignment with pumps
* [ ] Ensure that the end of the the intake tubing for each pump reaches the bottom of bottle/jar
* [ ] Double check: the correct tube (intake) for the correct pump is going into the correct bottle/jar
* [ ] Double check: Within the admin menu the correct liquid is assigned the correct pump
* [ ] Visual check: all intake tubes are inside bottles/jars and outtake tubes are in the pouring spout
* [ ] Set the volume of each liquid within the dispenser menu, these can be estimates
* [ ] The physical elements of the setup are done now, visit the admin menu on the webapp
* [ ] Go to the 'menu' tab and use it to select the drinks that Bartendro will be serving
* [ ] Double check: you have all ingredients for the drinks in menu, if a liquid is missing bartendro will not pour it
* [ ] Save the menu and go to the main page of the webapp (menu view, not admin)
* [ ] Test each drink in your menu, ensure they pour well and no bugs manifest.
* [ ] If one drink is having issues, you can still opt to remove or change it from the admin menu
* [ ] Bartendro can now serve, every 30 minutes or so check if the bottles/jars are close to empty
* [ ] When a liquid is approaching empty, act preemptively and fill up the jar or replace the bottle
* [ ] When reloading a liquid you need to go to the Dispensers admin menu and update the volume there

## TAKEDOWN
* [ ] Make an early 'last call' for drinks, wait 10 minutes and make that call again.
* [ ] Get a towel, dish clothes, or paper towels - the table will get wet
* [ ] Remove all tubes from jars/bottles, and place the intake tubes inside an empty bucket
* [ ] Place an empty cup or bucket under the pouring spot to collect what remains in the tubes
* [ ] In the Dispenser menu, each pump has a 'forward' option. For each pump tap on this button.
* [ ] The tube should empty into the cup/bucket, with some residue drops visible inside (this is OK)
* [ ] Remove the collection cup/bucket and prepare to run the **CLEANING CYCLE** steps again
* [ ] Once cleaning cycle is complete the buckets can be emptied
* [ ] Remove all the gears from within each pump and collect them in a dry container (no humidity)
* [ ] Take a screen-shot of the 'trending drinks' from the webapp menu
* [ ] Turn off Bartendro and unplug the power supply
* [ ] Bartendro can now be stored, with cleaned tubes and no gears inside the peristaltic pumps
